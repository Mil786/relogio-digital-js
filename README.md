# 🕒 Relógio Digital Moderno

Este projeto é um relógio digital que se adapta ao horário do dia, com funcionalidades de troca de tema e persistência de dados.

## ✨ Funcionalidades
- **Relógio em tempo real**: Horas, minutos e segundos atualizados instantaneamente.
- **Saudação Dinâmica**: Mensagens de "Bom dia", "Boa tarde" ou "Boa noite" baseadas na hora.
- **Modo Dark/Light**: Alternância de cores para conforto visual.
- **Persistência**: O tema escolhido fica salvo mesmo se você fechar a página (LocalStorage).

## 🛠️ Tecnologias
- HTML5 / CSS3 (Variáveis e Glassmorphism)
- JavaScript Puro (Vanilla JS)
